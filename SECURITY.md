# Security

## Reporting a vulnerability

If you believe you have found a security vulnerability in TeamSBC, please
[report it privately on GitHub](https://github.com/teamsbc/distribution/security/advisories/new)
before disclosing the details publicly. Do not report vulnerabilities through
public issues.

Please include:

- The affected component and TeamSBC version or image.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue, including a proof of concept if available.
- Any relevant configuration or proposed mitigation.

Please allow the maintainers time to investigate and coordinate a fix and
disclosure with you. If the vulnerability is in an upstream project, its own
security reporting process may also be appropriate.
